# Release Notes

### 0.1.0 (Unreleased)

- Establish the reproducible .NET, JavaScript, and Python build and package foundation.
- Vendor byte-preserved stable-v1.0 and pinned-v1.1 specification snapshots with provenance.
- Replace the proof-of-concept API with the cross-runtime portable domain model and descriptor catalogs.
- Add strict embedded/external decoding, validation, structured diagnostics, and non-mutating canonical TSV/YAML encoding for SSSOM v1.0 and the pinned v1.1 draft.
- Add cross-runtime mapping authoring factories, deep cloning, prefix management, and record-ID-based add/find/replace/remove operations.
- Produce the stable `PolyglotSSSOM` NuGet package from the verified cross-runtime source tree.

### 0.1.0-alpha.1 (2026-08-26)

- Published the initial NuGet preview containing the portable model, strict codec, and mapping-authoring API.
